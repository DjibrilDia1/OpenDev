# Technology community logos

Downloaded from the projects' own sites on 2026-10-19. These assets identify
technology communities administered by OpenDev; they are not OpenDev's brand.
Their trademarks remain owned by their respective holders.

| Local file | Official source | Asset |
| --- | --- | --- |
| `react-official.svg` | [React documentation repository](https://github.com/reactjs/react.dev/blob/main/public/images/brand/logo_dark.svg) | [React symbol](https://raw.githubusercontent.com/reactjs/react.dev/main/public/images/brand/logo_dark.svg), cyan variant |
| `python-official.svg` | [Python Software Foundation logos](https://www.python.org/community/logos/) | [Two snakes SVG](https://s3.dualstack.us-east-2.amazonaws.com/pythondotorg-assets/media/files/python-logo-only.svg) |
| `typescript-official.svg` | [TypeScript branding](https://www.typescriptlang.org/branding/) | `ts-logo-128.svg` from the [official asset pack](https://www.typescriptlang.org/branding/typescript-design-assets.zip) |
| `fastapi-official.png` | [FastAPI documentation](https://fastapi.tiangolo.com/) | [Official favicon](https://fastapi.tiangolo.com/img/favicon.png), 144 × 144 |

SVGs contain no executable or external content. XML serialization was normalized;
Python's SVG has an explicit viewBox matching its original physical dimensions
so that it scales to small avatars. The artwork, proportions and colors are retained. Images are bundled locally
and displayed with `object-fit: contain`, without recoloring or network requests.
The older generic emblems remain available for the demonstration catalogue.
